# 云端加密货币市场扫描

**每 15 分钟**自动扫描币安全市场，出现正期望交易机会就推送到手机。

- 跑在 GitHub 的服务器上 —— 手机关机、App 关掉，照常运行
- 只用币安**公开行情数据**，不需要账户密钥（除非你额外开启持仓监控）
- 扫描结果会推送到 **Bark** App

---

## 它是怎么判断的

不是简单的"涨了就推"，而是三层过滤：

| 层 | 做什么 |
|---|---|
| **信号层** | 全市场多周期技术分析（4h/1h/1d K线、EMA、RSI、ATR、量比、相对BTC强弱），识别 5 类形态 |
| **回测层** | 每类形态按**当前市场状态**查历史期望值（20567 笔回测样本），负期望的直接剔除 |
| **决策层** | 叠加消息面情绪（恐慌贪婪指数、资金费率等），输出 A/B/C/D 分级 |

**大多数时候它不会推任何东西** —— 这是设计行为。没有正期望机会时它会保持沉默，只在「观察名单」里默默记录接近突破位的币种。

## 配置

### 必填：Bark 推送密钥

仓库 → **Settings → Secrets and variables → Actions → New repository secret**

- Name: `BARK_KEY`
- Secret: 你的 Bark 密钥（Bark App 首页那串字符）

### 可选：持仓监控

配了这两个才会额外监控你的币安合约持仓（浮亏扩大 / 接近强平时报警）：

- `BINANCE_API_KEY`
- `BINANCE_API_SECRET`

> ⚠️ 只读权限即可。**务必关闭提现、交易权限。**

### 可选：调整扫描范围

在 `scan.yml` 里改 `MIN_VOL`（最小成交额，默认 2000000 = 200 万 USDT）。
调高 → 只扫大币种，更快；调低 → 覆盖更多小币种，但噪音也更多。

---

## 调整运行频率

编辑 `.github/workflows/scan.yml`：

```yaml
on:
  schedule:
    - cron: '*/15 * * * *'   # 每 15 分钟
```

常用值：`*/10`（10分钟）、`*/30`（半小时）、`0 * * * *`（每小时）

> GitHub 的定时任务在高峰期可能延迟几分钟，这是正常的。

## 怎么知道它有没有在工作

**Actions 标签页** → 点最近一次运行 → 看日志。

正常运行会长这样：

```
=== 云端扫描 2026-09-20 16:33:00 ===
▶ 拉取全市场行情…
▶ 候选 169 个，开始多周期分析…
▶ 完成 166 个（失败 3），耗时 58s
🌐 上涨·高波 · 剔除 113 个 · 机会 0 个
👀 观察名单 8 个: TRX_USDT(1.2%), PROVE_USDT(2.0%)...
```

**Actions 标签页 → crypto-scan → Run workflow** 可以随时手动跑一次。

## 注意

- GitHub 对**长期无活动**的仓库会自动停用定时任务。本仓库每次运行都会提交状态文件，所以不会触发这个规则。
- 本项目输出的是**量化信号筛查，不是投资建议**。每笔交易都带止损，风险自负。
